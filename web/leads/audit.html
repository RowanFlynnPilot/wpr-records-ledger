The quarterly audit

Every quarter, Wausau Pilot & Review files the same simple public records request, in identical wording, with each records custodian the Closed Door Ledger covers. Because the request is the same everywhere, the answers can be compared: how long each agency took, what it charged, and whether any denial followed Wisconsin law.
